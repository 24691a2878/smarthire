# SmartHire - AI Resume Analyzer
AI platform that automates resume screening using NLP & ML and generates daily reports.

## Features
- AI Resume Scoring
- Daily Reports (CSV)
- Email Automation
- Dashboard with Logs

## Tech Stack
Python, Django, Scikit-learn

## How to Run
pip install -r requirements.txt
python manage.py runserver
